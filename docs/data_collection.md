# 무료 공개자료 수집 목록

## 분석 범위와 작업 원칙

- 주제: 비만 유형에 따른 당뇨병 단계의 차이: BMI와 허리둘레를 중심으로
- 자료: 질병관리청 2024년 국민건강영양조사
- 분석·전처리 코드는 모두 R로 작성한다.
- 저장소 변경은 브랜치에서 작업한 뒤 PR로 제출한다.
- 현재 문서는 수집 계획이다. 원시자료 다운로드와 실제 열 이름·표본 수 검증은 아직 수행하지 않았다.

## 1. 내려받을 자료

| 우선순위 | 자료 | 용도 | 비고 |
|---|---|---|---|
| 필수 | 2024년 기본DB(ALL DB; 지침서 표기 HN24_ALL) | Y, BMI·허리둘레, 가족력, 생활습관, 사회경제 변수, 표본설계 | SAS 또는 SPSS 형식 중 하나만 확보 |
| 필수 | 제9기(2022–2024) 원시자료 이용지침서 최신 배포본 | 변수 코드, 생성변수, 결측·비해당, 가중치 기준 | 제공받은 PDF와 최신 배포본 차이 확인 |
| 필수 확인 | 2024년 정오표·수정 및 추가공개 안내(게시된 경우) | 데이터 버전·변수 수정사항 확인 | 다운로드 날짜와 수정일 기록 |
| 참고 | 2024 국민건강통계 | 주요 지표의 정의·분포 대조 | 집계표를 개인자료에 결합하지 않음 |
| 조건부 | 2022·2023년 기본DB | 2024년만으로 희소 집단 분석이 어려울 때 기간 통합 검토 | 연도별 변수·정의 일치와 통합가중치 먼저 검토 |
| 현재 불필요 | 영양조사 개인별 식품섭취 상세자료·식품코드 자료 | 식습관·영양소 분석으로 확장할 때 사용 | 현재 확정 모형에는 영양변수가 없음 |

유료 데이터, 건강보험 청구자료, 별도 사망원인 연계자료는 현재 연구질문에 필요하지 않다. 다른 조사 출처의 개인자료를 동일인 자료처럼 결합하지 않는다.

## 2. 확보할 변수

아래 이름은 제공된 이용지침서의 변수설명서를 기준으로 한다. 원시자료의 실제 이름·대소문자·라벨·수록 여부를 R에서 다시 확인한다.

| 역할 | 항목 | 지침서 변수명 | 처리 방향 |
|---|---|---|---|
| Y | 당뇨병 단계 | HE_DM_HbA1c | 정상 / 전단계 / 당뇨병의 순서형 범주 |
| 핵심 X 원재료 | BMI | HE_BMI | BMI 기준 비만 여부 생성 |
| 핵심 X 원재료 | 허리둘레 | HE_wc | 성별에 따른 기준으로 복부비만 여부 생성 |
| 기본 특성 | 나이 | age | 연속형; 80세 이상 탑코딩 유의 |
| 기본 특성 | 성별 | sex | 원자료 라벨 확인 |
| 가족력 | 부·모·형제자매의 당뇨병 진단 | HE_DMfh1, HE_DMfh2, HE_DMfh3 | 양성 응답이 있으면 가족력 있음; 그 외 모름·비해당 조합을 확인해 없음/결측 결정 |
| 신체활동 | 유산소 신체활동 실천 | pa_aerobic | 충족 / 미충족 |
| 흡연 | 평생 흡연량·현재 흡연 여부 | BS1_1, BS3_1 | 비흡연 / 과거흡연 / 현재흡연으로 재분류; 일반담배 기준과 100개비 기준 적용 여부를 명시 |
| 음주 | 월간음주 여부 | dr_month | 있음 / 없음 |
| 사회경제 | 가구소득 사분위 | ho_incm | 하 / 중하 / 중상 / 상; 개인소득 incm과 구분 |
| 사회경제 | 교육 | edu | 초졸 이하 / 중졸 / 고졸 / 대졸 이상 |

sm_presnt는 현재흡연 여부 지표이므로, 이것 하나만으로 비흡연과 과거흡연을 구분하지 않는다.

### 표본설계·검증용 변수

| 용도 | 변수명 | 사용 |
|---|---|---|
| 개인 식별 | ID | 중복·결합 확인용; 모형의 X로 사용하지 않음 |
| 가구 식별 | ID_fam | 가구정보 점검용 |
| 조사연도·DB 버전 | year, mod_d | 2024년 자료와 수정 버전 확인 |
| 건강설문·검진 가중치 | wt_itvex | 현재 주 분석의 가중치 후보; 최종 사용 영역과 적합성 확인 |
| 분산추정 층·집락 | kstrata, psu | 복합표본 설계 반영 |
| 임신·공복 상태 | HE_prg, HE_dprg, HE_fst | 대상자 기준·생성변수 유효성 점검 |
| 신체계측 원자료 | HE_ht, HE_wt, HE_obe | BMI와 기존 비만 분류 대조 |
| Y 판정 원자료 | HE_glu, HE_HbA1c, DE1_dg, DE1_31, DE1_32 | 혈당·진단·약물복용 정보 대조; X에 투입하지 않음 |

지침서의 SAS 산출 예시와 변수설명서 사이에 당뇨병 생성변수 표기가 다를 수 있으므로, 실제 파일에서 해당 열과 값 라벨을 확인한 뒤 확정한다.

## 3. R에서 만들 분석변수

| 변수 | 생성 내용 |
|---|---|
| diabetes_stage | 정상 / 당뇨병 전단계 / 당뇨병 |
| obesity_type | BMI 비만·복부비만 모두 없음 / BMI 비만만 / 복부비만만 / 둘 다 있음 |
| diabetes_family_history | 가족력 있음 / 없음; 불명 응답은 자동으로 없음 처리하지 않음 |
| smoking_status | 비흡연 / 과거흡연 / 현재흡연 |

비만 분류 기준은 채택한 국내 지침을 인용해 별도 변수정의서에 확정한다. 'BMI 비만 아님'에는 정상체중 외에 비만전단계 등이 포함될 수 있으므로 '정상체중'과 혼용하지 않는다.

## 4. 다운로드 및 보관 순서

1. [국민건강영양조사 공식 홈페이지](https://knhanes.kdca.go.kr/knhanes/main.do)에서 원시자료 다운로드 메뉴로 이동한다.
2. 2024년 기본DB(ALL DB)를 선택한다.
3. 사이트에서 요구하는 이용자 확인·개인정보 동의·이용 서약 절차를 완료한다.
4. SAS 또는 SPSS 자료 중 하나와 이용지침서를 내려받는다. 별도 유료 SAS·SPSS 프로그램 구매는 필요하지 않다.
5. 다운로드 날짜, 파일명, 자료 수정일, 출처를 기록한다.
6. 원시자료는 각자 로컬의 data/raw/ 등에 보관하고 Git 추적에서 제외한다. 파생 개인자료도 공개 저장소에 게시하지 않는다.
7. R의 haven::read_sas() 또는 haven::read_sav()로 읽는다.
8. 실제 변수명·라벨·결측·집단별 인원을 점검하고 결과표와 코드를 PR로 공유한다.
