# 연령의 80세 이상 탑코딩 처리 기준

## 채택할 분석 기준

- 주 분석에서는 공개 연령 변수 `age`를 연속형 보정변수로 사용한다.
- `age = 80`은 정확히 만 80세가 아니라 **80세 이상**을 뜻한다. 원자료의 80을 그대로 사용한다.
- 탑코딩만을 이유로 관측치를 제외하지 않으며, 실제 연령을 추측해 85·90 등으로 대체하지 않는다. 원래 결측은 그대로 유지한다.
- 이 기준은 연령의 처리 방식이다. 분석대상의 하한(19세 이상 또는 30세 이상)과 전체 변수의 결측 처리 기준은 별도로 합의한다.

## 민감도 분석

주 분석의 연속형 연령을 다음 연령대로 교체한 보정 모형을 추가로 적합한다.

| 연령대 | 공개 age 값 |
|---|---|
| 19–29세 | 19–29 |
| 30–39세 | 30–39 |
| 40–49세 | 40–49 |
| 50–59세 | 50–59 |
| 60–69세 | 60–69 |
| 70–79세 | 70–79 |
| 80세 이상 | 80 |

분석대상을 30세 이상으로 정하면 19–29세 범주는 사용하지 않는다. 먼저 전체 복합표본 설계를 만든 뒤 `subset()`으로 최종 분석대상을 선택한다. 연속형 모형과 연령대 모형은 동일한 관측치·나머지 설명변수·가중치·층·집락 및 같은 회귀모형 종류를 사용한다.

핵심 비교 대상은 **비만 유형의 오즈비·95% 신뢰구간과 예측확률**이다. 방향과 크기가 달라지는지 확인하고 차이가 크면 함께 보고한다. 연령대 분석은 연령 보정 방식에 따른 민감도를 확인하는 것이며, 실제 80세 이상 연령을 복원하거나 탑코딩의 영향을 완전히 제거하는 방법은 아니다. 차이가 나더라도 탑코딩 때문이라고 단정하지 않는다.

이 문서는 분석 계획이며 민감도 모형은 아직 적합하지 않았다. 최종 표본에서 연령대별 인원과 모형 적합 가능성을 먼저 점검한다. 표본이 적다는 이유로 결과를 본 뒤 임의로 범주를 변경하지 않고, 조정이 필요하면 근거와 변경 내용을 기록한다.

## 해석과 보고

- 80세 이상 집단 내부의 연령 차이는 반영할 수 없다.
- 연령의 회귀계수는 탑코딩된 공개 연령값에 대한 계수다. 80세 이후에도 실제 나이 한 살 증가에 따른 관련성이 추정되었다고 해석하지 않는다.
- 공개 연령값의 평균·최댓값을 실제 평균 연령·실제 최고령으로 설명하지 않는다.
- 현재 기본 변수 점검표의 `recorded_mean`, `max_recorded`, `n_80plus` 표기를 유지한다.

### 보고서에 사용할 문구

> 연령은 연속형 보정변수로 사용하였다. 원자료에서 80세 이상은 모두 80으로 탑코딩되어 있어 공개된 값을 그대로 유지하였으며, 해당 관측치를 제외하거나 실제 연령을 임의로 추정하지 않았다. 이에 따라 80세 이상 집단 내부의 연령 차이는 반영할 수 없다. 연령 보정 방식에 따른 결과의 민감도를 확인하기 위해, 80세 이상을 별도 범주로 둔 연령대 보정 모형을 추가로 비교한다.

민감도 분석을 완료하면 마지막 문장을 실제 수행 내용과 결과에 맞춰 수정한다.
