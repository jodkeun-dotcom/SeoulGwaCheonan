# 비만 유형에 따른 당뇨병 단계의 차이
### BMI와 허리둘레를 중심으로

2026학년도 2학기 범주형자료분석 팀 프로젝트  
**팀원: 세은 · 민서 · 조은**

## 1. 연구 배경 및 목적

BMI는 키와 체중을 이용한 비만 지표이며, 허리둘레는 복부비만을 평가하는 지표이다. 두 지표에 따른 비만 분류가 항상 일치하는 것은 아니므로, 이를 함께 고려해 당뇨병 상태의 차이를 살펴보고자 한다.

본 연구는 BMI 기준 비만과 복부비만 여부를 조합한 네 집단의 당뇨병 단계 분포를 비교한다. 나이, 성별, 가족력, 생활습관 및 사회경제적 요인을 고려한 뒤에도 집단 간 차이가 나타나는지 분석하고, 예방·관리 대상 선정에 대한 시사점을 도출한다.

> **핵심 연구질문**  
> BMI로는 비만이 아니어도, 복부비만이 있으면 당뇨병 단계의 분포가 다를까?

## 2. 사용 자료

- **주요 사용 영역:** 건강설문조사 및 검진조사
- **참고 문서:** 국민건강영양조사 제9기(2022–2024) 원시자료 이용지침서
- **분석대상:** 성인을 대상으로 하며, 세부 연령·포함·제외 기준은 지침서와 자료 점검 후 확정
- **공식 홈페이지:** [국민건강영양조사](https://knhanes.kdca.go.kr/knhanes/main.do)

영양조사 자료의 추가 사용 여부는 최종 변수 구성에 따라 결정한다. 분석에는 사용한 조사 영역에 적합한 가중치와 층화·집락 정보를 반영한다.

## 3. 변수 구성

### 반응변수 Y: 당뇨병 단계

| 범주 | 상태 |
|---|---|
| 1 | 정상 |
| 2 | 당뇨병 전단계 |
| 3 | 당뇨병 |

지침서의 당뇨병 상태 생성변수를 활용하되, 실제 변수명과 진단·약물복용·검사값 반영 기준을 확인한다. ‘단계’는 조사 당시 상태의 구분이며, 개인의 질병 진행을 관찰한 결과를 의미하지 않는다.

### 핵심 설명변수 X: 비만 유형

BMI 기준 비만 여부와 허리둘레 기준 복부비만 여부를 조합한다.

| 비만 유형 | BMI 기준 비만 | 복부비만 |
|---|---|---|
| ① 둘 다 없음 | 없음 | 없음 |
| ② BMI 비만만 있음 | 있음 | 없음 |
| ③ 복부비만만 있음 | 없음 | 있음 |
| ④ 둘 다 있음 | 있음 | 있음 |

분류 기준은 채택한 국내 기준과 이용지침서를 근거로 명시한다. 주 분석에는 비만 유형을 사용하고, BMI와 허리둘레를 별도의 설명변수로 중복 투입하지 않는다.

### 함께 고려할 설명변수

| 구분 | 변수 | 구성 |
|---|---|---|
| 기본 특성 | 나이 | 연속형 |
| 기본 특성 | 성별 | 원자료 분류 |
| 가족력 | 당뇨병 가족력 | 부모·형제자매 중 진단 경험 있음 / 없음 |
| 생활습관 | 신체활동 | 유산소 신체활동 지침 충족 / 미충족 |
| 생활습관 | 흡연 | 비흡연 / 과거흡연 / 현재흡연 |
| 생활습관 | 음주 | 월간음주 여부 |
| 사회경제 | 소득 | 가구소득 사분위 |
| 사회경제 | 교육 | 초졸 이하 / 중졸 / 고졸 / 대졸 이상 |

세부 코딩과 결측·비해당 처리 규칙은 변수정의서에 기록한다. 가족력의 ‘모름’은 ‘없음’으로 처리하지 않는다.

## 4. 분석 계획

### 전처리 및 기초분석

1. 원시자료 구조와 변수별 응답·결측 코드 확인
2. 분석대상 및 제외 기준 적용
3. 당뇨병 단계와 비만 유형 생성·검증
4. 비만 유형 × 당뇨병 단계별 실제 표본 수 확인
5. 복합표본 설계를 반영한 비율·기술통계·교차표 작성

### 회귀분석

당뇨병 단계의 순서를 고려해 **복합표본 순서형 로지스틱 회귀**를 우선 검토한다. 비례오즈 가정이 적절하지 않으면 **복합표본 다항 로지스틱 회귀**로 전환한다.

| 모형 | 설명변수 |
|---|---|
| 모형 1 | 비만 유형 + 나이 + 성별 |
| 모형 2 | 모형 1 + 당뇨병 가족력 + 신체활동 + 흡연 + 음주 |
| 모형 3 | 모형 2 + 소득 + 교육 |

- 모형 간 비교에는 동일한 분석대상을 사용한다.
- 변수 간 중복·다중공선성과 모형 가정을 점검한다.
- 오즈비와 95% 신뢰구간을 제시한다.
- 비만 유형별 정상·당뇨병 전단계·당뇨병의 예측확률을 비교한다.
- 공복혈당·당화혈색소 등 Y 분류에 사용한 정보는 X에 포함하지 않는다.

- **주차별 통합 담당:** 1주차 조은 → 2주차 세은 → 3주차 민서

- 모형 선택, 가정 검토 및 최종 결론은 공동으로 결정한다.

## 8. 해석 시 유의사항

본 연구는 단면자료 분석이므로 비만 유형과 당뇨병 상태의 **관련성**을 평가한다. 비만이 당뇨병을 유발했다거나, 특정 집단에서 향후 당뇨병이 발생한다고 단정하지 않는다.

또한 진단 이후의 체중·생활습관 변화, 설문 응답 오차, 결측 및 집단별 표본 수의 한계를 함께 검토한다.
