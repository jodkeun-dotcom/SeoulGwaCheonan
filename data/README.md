# 로컬 원시자료 준비 및 R에서 열기

원시자료는 각 팀원이 공식 홈페이지에서 이용 절차를 완료한 뒤 내려받는다.

## 파일 배치

저장소 루트에 다음 경로를 만든 뒤 ZIP을 복사한다.

    data/raw/HN24_ALL(SAS).zip

data/raw/와 data/processed/는 Git 추적에서 제외된다. 개인별 원본·파생자료를 PR에 포함하지 않는다. 파일은 팀원의 컴퓨터에만 저장되고 GitHub에서 자동 동기화되지 않는다.

## RStudio에서 실행

저장소 루트를 작업 디렉터리로 설정한다.

```r
# 처음 한 번만 설치
install.packages("haven")

source("R/read_knhanes_2024.R")
hn24 <- read_knhanes_2024()
```

파일을 다른 곳에 보관한다면 직접 선택할 수 있다.

```r
hn24 <- read_knhanes_2024(file.choose())
```

SAS 설치는 필요하지 않다. ZIP에서 자료를 임시 폴더에 풀어 R로 읽은 뒤 임시파일을 삭제한다. 원본 ZIP은 변경하지 않는다.

## 제공된 파일 확인 결과

- 파일: HN24_ALL(SAS).zip
- 내부 파일: hn24_all.sas7bdat
- ZIP 크기: 9,890,201바이트
- MD5: 47f785983e63d0de25f46116cff6be6c
- R로 읽은 전체 자료: 6,997행 × 813열
- 실제 당뇨병 단계 변수: HE_DM_HbA1c
- 계획한 BMI·허리둘레, 나이·성별, 가족력·생활습관, 소득·교육 및 표본설계 필수 변수 수록 확인
- 위 인원은 분석대상 기준과 결측 제외를 적용하기 전 전체 인원이다.
- 값·라벨 및 결측 처리, 비만 유형 생성, 분석표본 확정은 후속 전처리에서 수행한다.

다른 수정 버전을 받으면 파일 크기·해시·변수 구성이 다를 수 있으므로 다운로드 날짜와 DB 수정일을 별도로 기록한다.

## 원본을 공개 저장소에 넣지 않은 이유

제공된 『국민건강영양조사 제9기(2022–2024) 원시자료 이용지침서』 책자 247쪽의 원시자료 공개절차 규정에는 이용자 준수사항으로 “자료의 무단 공유ㆍ복제 및 사전에 명시한 목적 외 재활용 금지”가 명시되어 있다. 현재 저장소가 공개 상태이고 공개 재배포 허용을 확인하지 못했으므로, 이 PR에는 원본 대신 불러오기 코드와 준비 안내를 포함한다.

원본의 공식 출처: [국민건강영양조사](https://knhanes.kdca.go.kr/knhanes/main.do)
